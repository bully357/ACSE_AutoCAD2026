═══════════════════════════════════════════════════════════════
  EXIT CRASH FIX - DETAILED FLOW
═══════════════════════════════════════════════════════════════

    User clicks File → Exit in AutoCAD
              │
              ▼
    AutoCAD calls AcsePlugin.Terminate()
              │
              ├─► Step 1: CloseUi()
              │   ├─ Check if WPF window exists
              │   ├─ Close window if visible
              │   └─ Set window reference to null
              │
              ├─► Step 2: FreeAllGCHandles()
              │   │
              │   ├─ Reflection: Find ComplianceCommands
              │   │   ├─ Get _pinnedInstance field
              │   │   ├─ Get GCHandle value
              │   │   ├─ Call handle.Free()
              │   │   └─ Log: "Freed GCHandle for ComplianceCommands"
              │   │
              │   ├─ Reflection: Find TemplateCommands
              │   │   ├─ Get _pinnedInstance field
              │   │   ├─ Get GCHandle value
              │   │   ├─ Call handle.Free()
              │   │   └─ Log: "Freed GCHandle for TemplateCommands"
              │   │
              │   └─ Reflection: Find ExtractCommands
              │       ├─ Get _pinnedInstance field
              │       ├─ Get GCHandle value
              │       ├─ Call handle.Free()
              │       └─ Log: "Freed GCHandle for ExtractCommands"
              │
              ├─► Step 3: Unsubscribe events
              │   └─ DocumentManager.DocumentActivated -= ...
              │
              ├─► Step 4: Write unload message
              │   └─ Editor: "ACSE Plugin unloaded."
              │
              └─► Step 5: Final log
                  └─ Log: "ACSE Plugin terminated successfully"
                      │
                      ▼
              AutoCAD continues shutdown
                      │
                      ▼
              ✅ Exit successful (no crash!)
