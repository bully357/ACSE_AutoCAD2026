COMMAND: ACSE_GLOBAL_TEXT

═══════════════════════════════════════════════════════════════
   🚀 QUICK START
═══════════════════════════════════════════════════════════════

1. Type: ACSE_GLOBAL_TEXT
2. Click "Scan Drawing"
3. Select entities to modify
4. Check properties to change
5. Set new values
6. Click "Apply Changes"

═══════════════════════════════════════════════════════════════
   📋 WHAT IT DOES
═══════════════════════════════════════════════════════════════

Globally modify text/mtext properties:

✅ Text Style       ✅ Rotation
✅ Height           ✅ Width Factor
✅ Annotative       ✅ Justification (DBText)
✅ Layer            ✅ Attachment (MText)

═══════════════════════════════════════════════════════════════
   🔍 FILTER OPTIONS
═══════════════════════════════════════════════════════════════

Find specific text before modifying:

• Text Style (e.g., "Arial")
• Layer (e.g., "Text")
• Font File (e.g., "romans")
• Height Range (Min/Max)
• Annotative Only (Yes/No)

═══════════════════════════════════════════════════════════════
   💡 COMMON TASKS
═══════════════════════════════════════════════════════════════

Change Text Style:
   1. Filter: Text Style = "Arial"
   2. Scan
   3. Select All
   4. Modify: Text Style = "Romans"
   5. Apply

Make Text Annotative:
   1. Filter: Layer = "Dimensions"
   2. Scan
   3. Select All
   4. Modify: Annotative = Yes
   5. Apply

Fix Text Height:
   1. Filter: Max Height = 0.08
   2. Scan
   3. Select All
   4. Modify: Height = 0.125
   5. Apply

Move to New Layer:
   1. Filter: Layer = "OldLayer"
   2. Scan
   3. Select All
   4. Modify: Layer = "NewLayer"
   5. Apply

═══════════════════════════════════════════════════════════════
   ⚠️ IMPORTANT TIPS
═══════════════════════════════════════════════════════════════

✅ Save your drawing first (QSAVE)
✅ Use filters to target specific text
✅ Preview before applying
✅ Use UNDO to revert if needed
✅ Only checked properties change
✅ Unchecked properties stay same
