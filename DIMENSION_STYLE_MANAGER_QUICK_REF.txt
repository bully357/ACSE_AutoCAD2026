• Scale factor             (DIMLFAC)
• Annotative setting       (DIMANNO)

• Lineweights             (DIMLWD, DIMLWE)
• Text gap                 (DIMGAP)

  "DimTextGap": 0.09,

🎯 USAGE EXAMPLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example 1: Check Compliance Only
   ACSE_DIMMGR
   (Review audit, press Enter for all prompts)
   (No changes if you don't enter values)

Example 2: Create Standard Style
   ACSE_LOAD_TEMPLATE → Standards_EXAMPLE_Advanced.json
   ACSE_DIMMGR
   (Press Enter for all prompts to accept defaults)
   Result: "ASBUILT" style created with standard settings

Example 3: Custom Text Height
   ACSE_DIMMGR
   Prompt: "Text height (current: 0.125):"
   Enter: 0.1875
   (Press Enter for remaining prompts)
   Result: Style updated with 0.1875 text height

Example 4: Batch Processing
   ACSE_LOAD_TEMPLATE
   ACSE_DIMMGR_BATCH
   (No prompts - fully automated)
   Result: Style standardized using JSON values

🔗 INTEGRATION

Recommended Workflow:
   1. ACSE_LOAD_TEMPLATE        Load standards
   2. ACSE_DIMMGR_BATCH         Standardize styles
   3. ACSE_SCAN                 Check for violations
   4. ACSE_SCAN_INTERACTIVE     Fix violations

Alternative:
   1. ACSE_SCAN                 Identify issues
   2. ACSE_DIMMGR               Fix dimension styles
   3. ACSE_SCAN_INTERACTIVE     Fix remaining issues
