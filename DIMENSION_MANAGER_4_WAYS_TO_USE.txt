   METHOD 2: UI BUTTON (VISUAL)
═══════════════════════════════════════════════════════════════

Where: Scan Window → "📏 Dim Styles" button

What It Does:
   • Standardizes dimension styles
   • Shows result in message box
   • Easy to use!

Best For:
   • Visual users
   • Integrated with scan workflow
   • Quick access

Steps:
   1. Type: ACSE_SCAN
   2. Window opens
   3. Click: Scan button
   4. Click: "📏 Dim Styles" button (purple)
   5. Wait for result message
   6. Click: Rescan
   7. Done!

═══════════════════════════════════════════════════════════════
   METHOD 3: PRE-SCAN PROMPT
═══════════════════════════════════════════════════════════════

Command: ACSE_RUN

What It Does:
   • Prompts to standardize before scan
   • Optional (can skip)
   • Reduces violations

Best For:
   • Existing ACSE_RUN users
   • Optional standardization
   • Quick workflow

Steps:
   1. Type: ACSE_RUN
   2. Prompt: "Standardize dimension styles? (Y/N):"
   3. Press: Y (or N to skip)
   4. Scan continues
   5. Done!
