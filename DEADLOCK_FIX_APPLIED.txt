PROBLEM: Calling AutoCAD API from UI thread caused deadlock
FIX: Moved all AutoCAD API calls outside Dispatcher.Invoke()
STATUS: ✅ FIXED

═══════════════════════════════════════════════════════════════
   ❌ WHAT WAS WRONG
═══════════════════════════════════════════════════════════════

Bad Code (Caused Deadlock):

   Application.Idle += (s, ev) =>  // AutoCAD thread
   {
       var results = ScanEntities();  // ✅ OK
       
       Dispatcher.Invoke(() =>        // Switch to UI thread
       {
           doc.Editor.WriteMessage(); // ❌ DEADLOCK!
           // Trying to call AutoCAD API from UI thread!
       });
   };

Result:
   - UI thread waits for AutoCAD
   - AutoCAD frozen
   - Complete deadlock
   - Can't access F2 text window
   - Must kill AutoCAD

═══════════════════════════════════════════════════════════════
   ✅ WHAT WAS FIXED
═══════════════════════════════════════════════════════════════

Good Code (No Deadlock):

   Application.Idle += (s, ev) =>  // AutoCAD thread
   {
       doc.Editor.WriteMessage();  // ✅ On AutoCAD thread
       
       var results = ScanEntities();  // ✅ On AutoCAD thread
       
       Dispatcher.Invoke(() =>        // Switch to UI thread
       {
           // Update UI ONLY - no AutoCAD API!
           _textEntities.Clear();     // ✅ UI operation
           foreach (var info in results)
               _textEntities.Add(...); // ✅ UI operation
           StatusText = "Done";       // ✅ UI operation
       });
       
       doc.Editor.WriteMessage();  // ✅ Back on AutoCAD thread
   };

Result:
   - No AutoCAD API calls from UI thread
   - No deadlock
   - Scan completes
   - Results displayed
   - ✅ WORKS!
