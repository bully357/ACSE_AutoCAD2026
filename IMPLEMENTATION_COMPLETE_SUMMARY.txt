═══════════════════════════════════════════════════════════════════
   🎓 HOW THE SMART FIX ALGORITHM WORKS
═══════════════════════════════════════════════════════════════════

STEP 1: FREQUENCY ANALYSIS
──────────────────────────────────────────────────────────────────
Before scoring any violation, count how many times each rule ID
appears in the scan results.

Example: If "TS-001" (text style violation) appears 12 times,
         this boosts confidence for all TS-001 violations.

STEP 2: FACTOR CALCULATION
──────────────────────────────────────────────────────────────────
For each violation, calculate 5 factor scores:

1. LayerCriticality (30% weight)
   - High score if violation type = Layer
   - Layer fixes are very safe

2. DimStyleReliability (25% weight)
   - High score if violation type = DimStyle
   - Dimension style changes are reliable

3. TextConsistency (20% weight)
   - High score if violation type = TextStyle or Attribute
   - Text fixes are generally safe

4. FrequencyBonus (15% weight)
   - High score if violation appears 5+ times
   - Common violations = likely correct fix

5. SideEffectRisk (10% weight)
   - Penalty if entity is Block or Xref
   - Avoid risky operations on complex entities

STEP 3: WEIGHTED SUM
──────────────────────────────────────────────────────────────────
Final Confidence = Sum of (Factor Score × Weight)

Example:
LayerCriticality:    0.95 × 0.30 = 0.285
DimStyleReliability: 0.92 × 0.25 = 0.230
TextConsistency:     0.88 × 0.20 = 0.176
FrequencyBonus:      1.00 × 0.15 = 0.150 (12 occurrences!)
SideEffectRisk:      0.70 × 0.10 = 0.070
─────────────────────────────────────
Total Confidence = 0.911 = 91.1%

STEP 4: RECOMMENDATION
──────────────────────────────────────────────────────────────────
if (Confidence >= 0.90) → Safe
else if (Confidence >= 0.70) → Recommended
else → Manual Review

STEP 5: SUGGESTED ACTION
──────────────────────────────────────────────────────────────────
Generate user-friendly action text:
- "Move to layer 'ANNO-DIMN'"
- "Apply text style 'STANDARD' + height 0.125"
- "Change to dim style 'ASBUILT'"

STEP 6: APPLICATION
──────────────────────────────────────────────────────────────────
When user clicks a fix button:
- Safe Only: Apply only violations with recommendation = Safe
- Recommended: Apply Safe + Recommended
- Selected: Apply only checked violations
