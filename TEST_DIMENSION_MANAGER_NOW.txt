   ❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "No standards loaded"
   Solution: Run ACSE_LOAD_TEMPLATE first

Problem: "Command not found"
   Solution: Reload plugin (NETLOAD)

Problem: No prompts appear in ACSE_DIMMGR
   Solution: This is batch mode - use ACSE_DIMMGR (not _BATCH)

Problem: Style not created
   Solution: Check Standards.json has RequiredDimStyleName

Problem: Error message appears
   Solution: Check command line for details
            Press F2 to see full output
