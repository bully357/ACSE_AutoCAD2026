═══════════════════════════════════════════════════════════════
   🔍 WHAT WAS WRONG
═══════════════════════════════════════════════════════════════

Stack Trace Said:
   "TwoWay binding cannot work on read-only property 'IsAnnotative'"

The Problem:
   - DataGrid has CheckBox column for IsAnnotative
   - Default binding mode for CheckBox = TwoWay
   - IsAnnotative property = read-only (no setter)
   - WPF crashed when trying to create binding!

Where It Crashed:
   - Scan completed ✅
   - Items added to collection ✅
   - DataGrid started binding ❌ CRASH!

═══════════════════════════════════════════════════════════════
   ✅ THE FIX
═══════════════════════════════════════════════════════════════

Changed Line 133 in GlobalTextModifierWindow.xaml:

BEFORE (Crash):
   <DataGridCheckBoxColumn Header="Annot" 
       Binding="{Binding IsAnnotative}" Width="50"/>

AFTER (Fixed):
   <DataGridCheckBoxColumn Header="Annot" 
       Binding="{Binding IsAnnotative, Mode=OneWay}" Width="50"/>

Mode=OneWay tells WPF:
   "This property is read-only, don't try to write to it!"
