You reported:
   "Scan works, but modifications don't apply to drawing"

The Problem:
   - Scan button: ✅ Fixed (uses Application.Idle)
   - Apply button: ❌ Calling database from UI thread!
   - Preview button: ❌ Calling database from UI thread!

What Happened:
   1. Click "Apply Changes"
   2. ApplyButton_Click → On UI thread
   3. Call GlobalTextModifier.ApplyModifications()
   4. Inside: doc.LockDocument() → Tries to lock from UI thread!
   5. Lock fails or deadlocks
   6. NO CHANGES APPLIED!

═══════════════════════════════════════════════════════════════
   ✅ WHAT WAS FIXED
═══════════════════════════════════════════════════════════════

Fixed Flow (Apply Button):
   1. Click "Apply Changes" → On UI thread
   2. Show confirmation dialog → On UI thread
   3. Register Application.Idle handler → Returns immediately
   4. AutoCAD idle → Handler fires on AutoCAD thread!
   5. Call GlobalTextModifier.ApplyModifications()
      → NOW on AutoCAD thread!
   6. doc.LockDocument() → Safe! ✅
   7. Apply changes → Works! ✅
   8. Dispatcher.Invoke → Update UI on UI thread ✅

Fixed Flow (Preview Button):
   - Same pattern!
   - previewMode = true (no actual changes)
   - But needs correct thread for database access
