THE BUG:
   I was calling doc.Editor.WriteMessage()
   INSIDE Dispatcher.Invoke() ❌
   
   This means:
   - We're on UI thread
   - Trying to call AutoCAD API
   - DEADLOCK! ❌

THE FIX:
   Moved ALL doc.Editor.WriteMessage()
   OUTSIDE Dispatcher.Invoke() ✅
   
   Now:
   - AutoCAD API called on AutoCAD thread ✅
   - UI updated on UI thread ✅
   - No deadlock! ✅
