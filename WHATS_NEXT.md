Threading in WPF + AutoCAD:

WPF Data Binding:

   ✓ Read-only properties need Mode=OneWay
   ✓ Test with actual data early

Debugging:

   🆘 IF ISSUES ARISE
═══════════════════════════════════════════════════════════════

Troubleshooting Steps:

1. Check AutoCAD Version
   - Plugin is for AutoCAD 2026
   - Other versions may need recompilation

2. Check .NET Version
   - Requires .NET 8.0 Desktop Runtime
   - Install if missing

3. Check DLL Location
   - Unblock DLL if from internet (Properties → Unblock)
   - Ensure path has no special characters

4. Check Logs
   - C:\ACSE\acse_debug.log
   - AutoCAD command line (F2)

5. Rebuild if Needed
   - Source code available
   - dotnet build -c Release
